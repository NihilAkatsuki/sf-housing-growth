# San Francisco Housing Growth — Midterm

Project: *Housing Growth, Neighborhood Inequality, and Zoning Capacity in San Francisco*

## Layout

- `data/raw/` — original, unmodified downloads.
- `data/processed/` — filtered, cleaned, joined and tract-level datasets.
- `analysis/` — active Python implementations (one version per step).
- `notebooks/` — exploration and teammates' notebooks.
- `visualizations/` — figures referenced by the Midterm PDF.
- `outputs/tables/` — comparison summaries and other presentation tables.
- `docs/` — data-cleaning and method documentation.

## Data provenance and quality caveats

- `housing_production_filtered.csv` is derived data (not an original download).
- `sf_land_use_clean.csv` is a more recent Land Use snapshot, **not an
  authenticated 2008 baseline**. Verify the historical stock methodology before
  interpreting the 2005 baseline and growth-rate outputs.
- Earlier joined housing records have incomplete geolocation coverage; tract
  summaries are not necessarily full-city housing additions.
- Confirm whether `dbi_all_study_permit_coordinates.json` was downloaded raw
  or generated as a derived file; move to `data/processed/` if generated.
- Review `MIGRATION_REVIEW.md` for potentially divergent duplicate files.
